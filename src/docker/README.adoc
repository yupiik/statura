= Docker compose test

Use this docker compose project to test a jdbc connexion.

== Copy the JDBC drivers

Copy from https://jdbc.postgresql.org/download/postgresql-42.7.13.jar into the `./custom` directory.

== Run the docker compose

[source,bash]
----
docker compose up
----
